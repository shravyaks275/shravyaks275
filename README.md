# 📁 Featured Project Case Studies

### 🐕 1. Stray Dog Digital Health Passport 
* **The Product Lens (PM):** Identified a critical tracking gap among street animal rescue networks. Scoped a targeted MVP to eliminate data fragmentation across regional shelters.
* **The Engineering Lens (MERN):** Architected the fluid frontend using Next.js 15 and Tailwind CSS v4 for absolute field-level mobile responsiveness. Engineered a decoupled backend logic framework aligned with Clean Architecture boundaries.

### 📊 2. ScrapeWise E-Commerce Platform
* **The Product Lens (PM):** Conducted competitive analysis on e-commerce retail workflows. Translated raw web data scrapers into actionable market dashboards utilizing customer sentiment telemetry.
* **The Engineering Lens (MERN):** Automated massive data extraction pipelines utilizing Puppeteer and Axios. Built optimized serialization routines to output cleanly structured JSON payloads for rapid frontend rendering.

### 🔐 3. Smart Inventory Manager
* **The Product Lens (PM):** Mapped enterprise inventory discrepancies to unauthenticated access vectors. Designed centralized RBAC modules to defend warehouse transactions.
* **The Engineering Lens (MERN):** Implemented strict JWT token state management infrastructure. Modeled auth routing systems to emulate federated enterprise single sign-on (SSO) and OIDC handshakes.
